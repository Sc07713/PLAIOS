## Decision Frameworks

- **Build vs Learn** — Is this a learning exercise or a shipping exercise? Different standards apply.
- **Tool Selection** — Use simplest tool that solves the problem. Don't over-engineer for learning's sake.
- **Project Viability** — Does this project have a user, even if just me? If not, it's a tutorial, not a project.

## Escalation Triggers

- Major API/SDK breaking change affecting active projects
- Project blocked on technical capability gap >1 week
- No hands-on building activity >2 weeks (reading without doing)
