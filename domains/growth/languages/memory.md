# Languages Sub-Domain Memory

Accumulated language learning knowledge across sessions. Stable facts, not current state.

## Cantonese

- **Learning since ~2011.** Started when dating Mina (now wife). ~15 years of on/off learning.
- **cantoneseplus.com** — Built by Scott. Started as a corpus project (scraped + compiled data), evolved into a community dictionary/resource. 2 native-speaker editors contribute. Originated because CantoShiek was poorly maintained and the community needed an alternative.
- **Comic books** — Owns a collection. Difficult to use for learning due to SWC (Standard Written Chinese) vs written Cantonese gap.
- **No immersion period** — Has never lived in a Cantonese-speaking environment. All exposure is via family and self-study.
- **Family context** — Mina and her family are Cantonese speakers. Passive exposure is constant.
