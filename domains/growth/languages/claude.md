# Languages Sub-Domain

## Identity

Active language learning across five target languages: Cantonese, Mandarin, Korean, Spanish, and Japanese. Nested under Growth as a specific, trackable component of L4.2 Learning. Each language has its own proficiency level, method, and practice cadence. Practical communication focus over academic perfection.

## Hierarchy Ownership

- Sub-component of **L4.2 Learning**

## Per-Language Tracking Format

Each language is tracked across:
- **Proficiency level:** Beginner / Elementary / Intermediate / Advanced
- **Active method:** Current primary learning approach
- **Practice frequency:** Target vs actual sessions per week
- **Next milestone:** Specific, measurable next goal

## Decision Frameworks

### Priority Ranking

Which language gets focus this quarter? Based on opportunity (upcoming travel, social context, professional need) and momentum (which language is currently flowing?). Re-evaluate quarterly.

### Method Selection

What's working? Switch methods before quitting a language. If a method isn't producing results after a fair trial (4-6 weeks of consistent practice), change the method — don't abandon the language.

### Time Budget

Languages share a fixed time allocation. Adding focus to one language means reducing another. Be explicit about trade-offs rather than pretending all five can advance simultaneously.

## Escalation Triggers

- No practice in any language >1 week
- A language with active investment showing no progress >2 months
