# Scott's Supplement Protocols -- Complete Reference

## Stack 1: Morning Cognitive Stack (Weekdays Only, Fasted)
**Timing:** Upon waking, 20-30 minutes before coffee.

| Compound | Dose | Mechanism | Notes |
|----------|------|-----------|-------|
| DLPA | 500-750mg | Primary dopamine precursor. D-form provides endorphin potentiation. | **Primary choice.** Softer, sustained curve vs tyrosine. |
| Rhodiola rosea | 500mg | Mild MAO inhibition extends dopamine half-life. Adaptogenic. | Daily weekday use. |
| Alpha-GPC | 300mg | Acetylcholine substrate. | 300mg not 600mg -- TMAO risk managed by cycling + moderate dose. |
| Creatine | 5g | ATP turnover, cognitive buffer, neuroprotective. | Daily including weekends (no tolerance). |
| Coffee | Diluted double shot | Caffeine + adenosine antagonism. | Morning only. |

**Weekend cycling:** DLPA, rhodiola, alpha-GPC OFF on weekends.

**Tactical alternatives (not daily):**
- **L-Tyrosine** -- acute high-demand. Military research supports sleep deprivation use.
- **Mucuna pruriens** -- "break glass in emergency." Contains L-DOPA directly. Feels "awful."
- **Huperzine A** -- 200mcg (not 400mcg). High-demand days only.

## Stack 3: Evening / Sleep Stack

### Core Foundation (Every Night)
| Compound | Dose | Mechanism |
|----------|------|-----------|
| Magnesium glycinate | 400-600mg elemental | GABA co-agonism, sleep architecture |
| L-Theanine | 200mg | Alpha wave promotion |
| Glycine | 3g | Core body temperature reduction. **PAUSE during extended fasts** (purine -> uric acid -> gout). |

### Cortisol Modulation Layer
- **Ashwagandha** -- CONTINUOUS baseline, 300-600mg. 8-12 week blocks. ~$0.17/day BulkSupplements.
- **Phosphatidylserine** -- ACUTE/SITUATIONAL. 100mg active (500mg powder = 100mg active). Blunts cortisol via ACTH dampening.
- **Magnolia bark** -- ACUTE/SITUATIONAL. 200-300mg. Direct GABA-A agonism.
- **Do NOT stack all three simultaneously** -- tolerance, can't isolate effects.

### Intimacy Protocol (Two-Phase)
**Phase 1 (before):** Mag 200mg, theanine 100-200mg, citrulline 3-6g, pycnogenol 100-200mg, ashwagandha 300mg
**Phase 2 (after):** Glycine 3g

## Stack 4: Extended Fast Electrolytes
- Sodium: 5g/day (~1.5 tsp regular salt + Lite Salt)
- Potassium: 3g/day (~2 tsp Diet Rite Lite Salt)
- Magnesium: Continue evening mag glycinate

**During extended fasts:**
- PAUSE glycine (gout risk)
- PAUSE cognitive stack entirely (dopaminergic reset)
- CONTINUE creatine + sleep stack minus glycine
- Bone broth 750ml-1L daily (skim fat)
- Baking soda protocol if gout flares

## Stack 5: Dopaminergic Reset (Every 8-12 Weeks)
Cycle off ALL cognitive enhancers during quarterly extended fasts. Resume after fast + 1-2 days refeed.

## Key Principles
1. Cost-effectiveness: bulk powders > capsules. BulkSupplements primary, VPA Australia for speed.
2. Weekend cycling prevents dopaminergic tolerance.
3. Quarterly extended fasts = full neurochemical reset.
4. Ashwagandha is continuous baseline, not cycled with dopaminergics.
5. Mag bisglycinate powder tastes terrible -- tablets preferred.
6. Subjective experience is valid data (DLPA > tyrosine, mucuna rejected).
7. Separate berberine from psyllium husk by 1+ hour.
