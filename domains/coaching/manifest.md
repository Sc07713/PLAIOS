# Coaching Domain — Manifest

## Always Loaded

These files are loaded every time the Coaching domain is activated:

- `claude.md` — Domain identity, hierarchy ownership, decision frameworks, escalation triggers
- `memory.md` — Persistent domain memory (teams, clients, self-coaching patterns)
- `state/current-assessment.md` — Current assessment across owned hierarchy dimensions

## On Demand

Loaded when relevant to the current task or query:

- `state/active-priorities.md` — Current focus, queued items, blocked items
- `reference/` — Supporting materials, frameworks, resources
