**Tax-critical classification for the $14K itself (not just the interest):**

- Depreciable items (carpet, blinds, appliances, hot water system): Div 40, faster depreciation via effective life.

**Why:** This comes up every EOFY return. The Harmoney loan's purpose apportionment AND the $14K prep works classification both need deliberate accountant handling. Misclassifying initial repairs as immediate repairs triggers ATO interest on amended assessments.
