**Don't diminish the value of Scott's savings.** When discussing his IBKR or other investment accounts, treat the actual capital as real money that deserves real strategy work. Don't frame the account as "small" or relativise it against assumed-larger-elsewhere positions.

**Why:** Scott pushed back 2026-05-15 after I called a ~$10.5K AUD IBKR account "small" and a "tactical sleeve" and said deploying SPY_top_K there would make it "more experiment than core allocation." That framing landed wrong — it's patronizing whether or not he has bigger accounts elsewhere, and it doesn't help him decide what to do with the capital he's asking about.

**How to apply:**
- When the user asks for deployment advice on a specific account, work with the actual numbers, not against an assumed larger context
- Don't conjecture about "where the bulk of wealth is" unless the user raises it
- If a deployment question hinges on knowing other holdings, ASK ONCE specifically — don't keep framing the current account as marginal
- Concrete order lists + specific share counts > hand-wavy "is this enough capital" questions
- Apply this rule to all financial discussions: PocketSmith balances, super accounts, equity holdings, cash reserves — treat them at face value
