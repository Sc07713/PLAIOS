- **V3.2 — Portfolio overlay. SHIPPED + pushed 2026-05-12** (commits e46375b…785c14f, GitHub Sc07713/trading-tools master; spec `docs/specs/2026-05-12-v3.2-portfolio-overlay.md`, plan `docs/plans/2026-05-12-v3.2-portfolio-overlay.md`). Equity-sleeve-only multi-instrument layer: a *portfolio run* takes one strategy, forward-fills its `entry_long`/`exit_long` into a per-name held-state (long-only — short cols ignored), and on a **weekly** cadence (∈ {daily,weekly,monthly}; rebalance bar = first available trading bar of each ISO week/month) holds ≤7 cash-equity positions + a **gold (GLD) residual sleeve** ("when in doubt hold gold" → zero theses = 100% GLD; one lone thesis = 60% it / 40% GLD). Two trim-to-7 modes: **basket** (greedy highest-avg-pairwise-|corr| drop, 120d window) and **rank_hold** (top-K≤7 by a strategy-emitted `score` — only `high_52w_breakout` has one: `close / rolling-252d-high`). Held names weighted **equal** (default) / **inv_vol** (60d) / **risk_parity** (120d cov, damped multiplicative ERC solver, inv-vol fallback), then a hard **60% per-position cap** (excess pro-rata, then to gold). Cost = one-way turnover × `cost_bps`/10000 per rebalance (default 5 bps). **Marking convention: buy-at-close / mark-at-close throughout** (deliberate simplification vs `_walk_signals`' next-bar-open — makes "100% gold ≡ gold-BH" an exact test). **Fit-only-K-on-IS:** rank_hold's K∈{3,5,7} is the *only* fitted param (grid-searched on first 70% of bars by cost-adj IS Sharpe, frozen, OOS on frozen K); 3-pt grid feeds DSR `n_trials`; basket has no fitted param ⇒ IS/OOS is a stability check there. **Four-way benchmark** (all mandatory): strategy / spy_bh / `universe_ew_bh` (1/N of each universe member, drift, one round-trip cost on last bar) / `gold_bh`. **Verdict** (strategy/OOS row): REAL EDGE = OOS Sharpe>0.9 ∧ DSR≥0.95 ∧ beats *both* universe_ew_bh & gold_bh OOS Sharpe; PROMISING = OOS Sharpe>0.9 ∧ PSR(0.9)≥0.95; else NO EDGE. New tables `portfolio_runs` + `portfolio_period_stats`; new modules `backtest/portfolio.py` + `portfolio_weights.py` + `run_portfolio_baseline.py`; `+generate_portfolio_charts` in `plots.py`; new `gold_buy_hold` strategy on GLD; GLD in `KNOWN_INSTRUMENTS` + `universe.GOLD_SYMBOL` (not in `TOP_25`); `high_52w_breakout` emits `score`; CLI `tt portfolio-backtest` + `tt portfolio-report`; artifacts `runs/portfolio/<id>/`; 126 tests pass (124 + 2 live-IB smoke). What shipped: **`position_management` field on `StrategyMeta`** (`"binary"` default — every existing strategy/benchmark bit-for-bit unchanged — `"tiered_meanrev"` new) + a `register()` kwarg (validated against `VALID_POSITION_MANAGEMENT`) + `to_db_row` + `db.upsert_strategy` cols + idempotent `strategies.position_management` column; **harness `_walk_tiered_meanrev`** — the decoded Pine state machine: dip-buy a full position at `min(bb_lower,open)` when `entry_long` (=`low<bb_lower`) → sell ½ at `max(bb_middle,open)` when `high≥bb_middle` (tier1) → sell ¼-of-original at `max(bb_upper,open)` when `high≥bb_upper` (tier2) → sell ⅛ at `min(bb_middle,open)` when `low≤bb_middle` (tier3) → ⅛ runner closes at break-even (`low≤entry_px`) or the lower band (`low≤bb_lower`); break-even closes at tiers 1/2/3; a `×stop_pct` (0.9) stop on the pre-tier-1 state; **re-entry = the `entry_long` flat rule re-firing** (same-bar after a close-at-lower; next qualifying bar after a no-tier stop that bottomed above the band — the signed-off reading, not "fill at lower on the stop bar"); **limit-at-level intrabar fills** (buy `min(L,open)` when `low≤L`; sell `max(M,open)` when `high≥M`; gap-through handled) — fixes the next-bar-open-bias debt *inside this mode* (`binary` unchanged); an **intrabar tier-cascade** mirroring the Pine branch order (a scale-out that bumps the tier lets the new tier's triggers fire the same bar); a **one-way-leg cost model** via cost-effective fill prices (buys ×(1+half_cost), sells ×(1−half_cost), `half_cost=(cost_bps/2)/10000`; a buy-full→scale-fully-out cycle ≈ a `cost_bps` round-trip); each realised scale-out/close is one trade-ledger row with an added `fraction` column.
