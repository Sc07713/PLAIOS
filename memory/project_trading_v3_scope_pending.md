SHIPPED + pushed 2026-05-12** (commits e46375b…785c14f, GitHub Sc07713/trading-tools master; spec `docs/specs/2026-05-12-v3.2-portfolio-overlay.md`, plan `docs/plans/2026-05-12-v3.2-portfolio-overlay.md`). Equity-sleeve-only multi-instrument layer: a *portfolio run* takes one strategy, forward-fills its `entry_long`/`exit_long` into a per-name held-state (long-only — short cols ignored), and on a **weekly** cadence (∈ {daily,weekly,monthly}; rebalance bar = first available trading bar of each ISO week/month) holds ≤7 cash-equity positions + a **gold (GLD) residual sleeve** ("when in doubt hold gold" → zero theses = 100% GLD; one lone thesis = 60% it / 40% GLD). Two trim-to-7 modes: **basket** (greedy highest-avg-pairwise-|corr| drop, 120d window) and **rank_hold** (top-K≤7 by a strategy-emitted `score` — only `high_52w_breakout` has one: `close / rolling-252d-high`). Held names weighted **equal** (default) / **inv_vol** (60d) / **risk_parity** (120d cov, damped multiplicative ERC solver, inv-vol fallback), then a hard **60% per-position cap** (excess pro-rata, then to gold). Cost = one-way turnover × `cost_bps`/10000 per rebalance (default 5 bps). **Marking convention: buy-at-close / mark-at-close throughout** (deliberate simplification vs `_walk_signals`' next-bar-open — makes "100% gold ≡ gold-BH" an exact test). **Fit-only-K-on-IS:** rank_hold's K∈{3,5,7} is the *only* fitted param (grid-searched on first 70% of bars by cost-adj IS Sharpe, frozen, OOS on frozen K); 3-pt grid feeds DSR `n_trials`; basket has no fitted param ⇒ IS/OOS is a stability check there. **Four-way benchmark** (all mandatory): strategy / spy_bh / `universe_ew_bh` (1/N of each universe member, drift, one round-trip cost on last bar) / `gold_bh`. **Verdict** (strategy/OOS row): REAL EDGE = OOS Sharpe>0.9 ∧ DSR≥0.95 ∧ beats *both* universe_ew_bh & gold_bh OOS Sharpe; PROMISING = OOS Sharpe>0.9 ∧ PSR(0.9)≥0.95; else NO EDGE.
