- **V3.2 — Portfolio overlay. DESIGNED 2026-05-12** — spec committed (`docs/specs/2026-05-12-v3.2-portfolio-overlay.md`, commit 0addc67); plan + implementation pending. Equity-sleeve-only multi-instrument layer: a *portfolio run* takes one strategy, forward-fills its `entry_long`/`exit_long` into a per-name held-state (long-only — short cols ignored), and on a **weekly** cadence (param ∈ {daily,weekly,monthly}) holds ≤7 cash-equity positions + a **gold (GLD) residual sleeve** ("when in doubt hold gold" → zero theses = 100% GLD; one lone thesis = 60% it / 40% GLD). Two modes (same machine, different trim-to-7 tie-break): **basket** (trim by greedy highest-pairwise-correlation drop, 120d window — the "independent bets" rule) and **rank_hold** (trim to top-K≤7 by a strategy-emitted `score` column — only `high_52w_breakout` gets one in V3.2: `close / rolling-252-high`). Held names weighted by **equal** (default) / **inv_vol** (60d) / **risk_parity** (120d cov), then a hard **60% per-position cap** (excess redistributed pro-rata, then to gold). Cost = one-way turnover × `cost_bps`/10000 per rebalance. **Fit-only-K-on-IS discipline:** rank_hold's K∈{3,5,7} is the *only* fitted param — grid-searched on the first 70% of bars by IS Sharpe, frozen, OOS reported on the frozen K (3-pt grid feeds DSR `n_trials`); basket mode has no fitted param so IS/OOS stays a stability check there. **Four-way benchmark:** strategy / spy_bh / `universe_ew_bh` (EW-BH of all 25) / `gold_bh` — all mandatory. **Verdict:** REAL EDGE = OOS Sharpe>0.9 ∧ DSR≥0.95 ∧ beats *both* universe_ew_bh & gold_bh OOS Sharpe (the beat-gold hurdle); PROMISING = OOS Sharpe>0.9 ∧ PSR(0.9)≥0.95; else NO EDGE. New tables `portfolio_runs` + `portfolio_period_stats`; new modules `backtest/portfolio.py` + `backtest/portfolio_weights.py` + `backtest/run_portfolio_baseline.py`; new strategy `gold_buy_hold` on GLD; GLD added to `KNOWN_INSTRUMENTS` (not `TOP_25`); CLI `portfolio-backtest` + `portfolio-report`; artifacts under `runs/portfolio/<id>/`. Baseline = 10 active strategies basket-mode + `high_52w_breakout` rank_hold(fit_k) + `asset_buy_hold` basket-mode (~12 runs) then DSR back-fill. Per-rebalance thesis ranking is emitted as the hook for the future options scanner. Diversification thesis: single-name edge ~0.5–0.8 → portfolio 0.9–1.1; also reports the Sharpe *lift vs each strategy's best single-name V3.1 run* even where nothing clears the bar. (NB the current `TOP_25` is ~20 mega-cap tech names — the opposite of decorrelated — so the V3.2 result on it is a *lower bound*; see [[user_investment_philosophy]].)
